This site is a room. In **HIFI** it is drawn in 3D: you switch camera shots, hover over
things, put a tape into the VCR and hear the radio. In **LOFI** it is this page: the same
content as text, light enough for any screen.

The idea of a personal site that is a room comes from Felix Rieseberg. The room here is
built from scratch, with its own assets; the [replay](https://github.com/piabrota/room#replay-how-it-was-built)
in the README shows each prompt that made it.

## How a post is written

- a Markdown file in `posts/`, named `YYYY-MM-DD-slug.md`
- front matter with a `title`, a `date` and a one-line `summary`
- then the text: headings, lists, quotes, `code` and links

The newest post comes first, and the [feed](/feed.xml) lists them all.
